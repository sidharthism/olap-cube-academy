# Extractable Components

## Layout components

None. The generated RootLayout only wraps HTML, fonts, and children; it does not provide a reusable visual shell.

## Basic components

None. The starter has no shared UI primitives.

## Extraction decision

Skip component extraction for the first design. The only existing visual is a temporary route-specific loading placeholder that must be replaced, not preserved. Reusable product components such as MissionRail, ChapterNode, EvidenceDrawer, CubeGrid, QuizCard, and DecisionBriefDrawer will be implemented only after the Superdesign direction is approved.
