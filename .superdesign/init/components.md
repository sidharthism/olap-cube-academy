# Shared UI Components

## Framework

- React 19.2.6
- Vinext 1.0.0-beta.3 using Next.js App Router conventions
- Tailwind CSS 4.2.1 through the global stylesheet

## Component inventory

The generated starter does not contain a shared component directory or reusable UI primitives yet. Its only UI is the route-specific placeholder in app/page.tsx, so there is no shared Button, Card, Input, Dialog, Table, Tabs, navigation, or other component source to include.

The placeholder must not be extracted as a reusable component because it will be replaced by the approved product design.
